<section class="resume-section">
  <div class="resume-section-heading">
    <h2>Overview</h2>
  </div>
  <p class="resume-entry-summary">Caritas is a full-stack web application for case management workflows. I worked on the web platform and backend systems that supported active participant records, stakeholder requirements, and coordination with a related mobile app.

  The project focused on making sensitive case data easier to manage reliably. That meant designing backend structures, implementing APIs, and building authentication and access patterns that could support real operational use instead of just a prototype experience.</p>
</section>


<section class="resume-section">
  <div class="resume-section-heading">
    <h2>My Role</h2>
  </div>
  <article class="resume-entry">
    <ul>
      <li>I led development of the full-stack web app while coordinating backend requirements with the mobile app team, stakeholders, and case management workflows.</li>
      <li>A major part of my contribution was designing a unified backend data model for more than 40,000 active participant case records and turning that model into a scalable Express.js and MongoDB API.</li>
    </ul>
  </article>
</section>


<section class="resume-section">
  <div class="resume-section-heading">
    <h2>Backend Data Model & API</h2>
  </div>
  <p class="resume-entry-summary">I worked on the backend foundation that tied the web application together. The system needed to represent participant records consistently, expose data through predictable API routes, and stay flexible enough for changing stakeholder requirements.

I also helped implement role-based access and GDPR-conscious authentication patterns so the application could better handle sensitive case information. The work connected database design, API behavior, and user permissions into one coherent platform.</p>
  </section>


  <section class="resume-section">
  <div class="resume-section-heading">
    <h2>Outcome</h2>
  </div>
  <p class="resume-entry-summary">The result was a more dependable web application for case data management, with backend structures and access controls designed around real records, real users, and long-term maintainability.</p>
  </section>
